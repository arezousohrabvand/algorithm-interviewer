# AI-Assisted Algorithm Interview

## Goal

Evaluate whether the candidate can work effectively with an AI coding assistant.

Do not test whether AI can solve the question.

Test whether the candidate can:

- understand the problem
- select an algorithm
- write a useful AI prompt
- review AI-generated code
- find bugs
- challenge assumptions
- test the solution
- verify complexity
- improve AI output

## Flow

### 1. Candidate reasons first

Before AI:

- explain problem
- identify likely pattern
- give brute-force idea
- discuss expected complexity
- identify edge cases

### 2. Candidate prompts AI

Ask:

"You may now use an AI assistant. What would you ask it?"

Evaluate:

- task clarity
- language
- constraints
- expected output
- complexity goal
- restrictions
- edge cases

### 3. Review AI output

Sometimes give correct output.

Sometimes intentionally include:

- off-by-one error
- wrong loop condition
- wrong pointer update
- wrong complexity
- hidden O(n)
- unnecessary sorting
- input mutation
- duplicate bug
- invalid assumption
- hallucinated API
- infinite loop

Ask:

"Would you ship this code? Why?"

### 4. Candidate explains code

Require:

- algorithm
- control flow
- correctness
- complexity
- assumptions

### 5. Candidate tests it

Require independent test cases.

### 6. Follow-up

Change one requirement and make the candidate adapt.
