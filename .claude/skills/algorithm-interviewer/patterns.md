# Algorithm Pattern Recognition

## Binary Search

Signals:

- sorted array
- sorted search space
- first occurrence
- last occurrence
- threshold
- first true
- last false
- minimum valid value
- maximum valid value
- monotonic condition

Mental model:

Can I eliminate half of the remaining possibilities?

---

## Hash Map

Signals:

- fast lookup
- duplicates
- frequency counts
- pair matching
- complements
- grouping
- remember previously seen values

Mental model:

What information would be useful to remember while scanning?

---

## Two Pointers

Signals:

- sorted array
- pair problem
- opposite ends
- palindrome
- remove duplicates
- partition

Mental model:

Can two positions move intelligently instead of restarting work?

---

## Sliding Window

Signals:

- contiguous subarray
- contiguous substring
- longest
- shortest
- at most K
- minimum window
- maximum window

Mental model:

Can I maintain a moving valid range?

---

## Stack

Signals:

- nested structure
- parentheses
- undo
- previous greater/smaller
- expression evaluation

---

## BFS

Signals:

- shortest path in unweighted graph
- nearest
- level-by-level
- minimum number of steps

---

## DFS

Signals:

- connected components
- reachability
- tree traversal
- graph traversal
- explore paths

---

## Heap

Signals:

- top K
- smallest K
- largest K
- continuously need min/max
- priority

---

## Backtracking

Signals:

- all combinations
- permutations
- all arrangements
- choose / explore / undo

---

## Dynamic Programming

Signals:

- repeated subproblems
- count ways
- minimum cost
- maximum score
- choose / skip
