# Study Sources

## AlgoMonster

The user has an active AlgoMonster subscription.

When AlgoMonster access is available through Playwright:

Use it to:

- inspect the user's current AlgoMonster learning topic
- read lessons the user is authorized to access
- identify relevant practice questions
- identify difficulty and pattern
- understand the curriculum sequence
- check which problems the user has already completed

Do not bulk-download or mirror the entire course.

Use AlgoMonster as a live study source.

Prefer storing locally:

- lesson title
- topic
- problem title
- difficulty
- source URL/reference
- completion status
- user's weaknesses

Do not store full proprietary course copies unless the user explicitly supplies the content for local study.
